# OSS・第三者著作物・安全性 / 2026-11-21

## 基本原則
- ゲームシステムの発想を参考にすることと、既存ゲームの**具体的な表現・コード・アート・音・クライアント・データを流用することを分離**する。
- 『トリックスター』『Tree of Savior』『ラグナロクオンライン』のキャラクター、地形、アイコン、シナリオ、リバースエンジニアリング由来資料はゲーム本体に取り込まない。
- GitHub公開=商用利用許可ではない。ライセンスと、素材・依存ライブラリの別ライセンスを確認する。
- このPoCのコードは新規実装で、第三者ライブラリを含まない。ユーザー自身がリポジトリの公開範囲とライセンスを確定する。

## 本番セキュリティゲート
- Supabase Auth等の確立した認証を使用。独自生パスワード比較禁止。
- WebSocket接続時に認証・Origin・バージョン検査とメッセージ単位の権限検証。レート/サイズ制限・切断時復帰。
- プレイヤー位置・高さ・床階層・速度・射程・攻撃/スキルCT・発掘ポイント・発掘時間・報酬抽選はサーバー確定。
- アイテムの取得・投棄・倉庫/取引移動・課金付与はサーバーDBトランザクションで原子的に更新。リクエスト重複でも二重取得不可。
- 依存ライブラリのlockfile、SBOM、LICENSE/NOTICE、脆弱性スキャンを保守する。
- 現金課金を導入する場合、Stripe等の決済代行加盟店審査・特商法・未成年対策を実装前に再調査。カード番号を独自DBに保持しない。
- 本リポジトリはユーザーが公開設定で作成したため、秘密/トークン/未承認の外部画像をコミットしない。
