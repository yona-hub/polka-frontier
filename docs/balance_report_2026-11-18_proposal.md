# オリジナルMMORPG 戦闘バランス検証レポート 試案 v1.2

作成日: 2026-11-18

**注意:** 以下の装備・敵の数値や係数は、当時の実装から取得した確定値ではなく、新作のために仮置きした検証入力。ゲームに実装して測定した実績ではない。

## 1. 設計結論

- 成長グラフ・4BP/レベル・12能力は維持。
- 属性は物理防御で軽減されない追加成分（属性耐性で調整）。原作導入時の説明と整合する方向。
- 通常武器でも同格狩りは成立する。高属性剣は高防御を突破できるが、格上狩りの生存性までは保証しない。
- 殴り魔のAP極、幸運属性剣、銃火力の立ち撃ちは死亡率が高い。装備と立ち回りの代償を数値で残す。
- 回避・感知・HP依存の戦闘型は同格で成立するが、HP依存は時間経過と自己消費によって弱くなる点に注意。
- 攻撃速度極は高レベルで攻撃極より大きく劣るため、手数連動の追撃ノードを試験。

## 2. テスト方法

- 15ビルド、Base20/60/100/140の4レベル。Level20/60/100は同格一般敵、Level140は一般・属性弱点・属性耐性・高回避・魔法敵・+30レベル重装敵の6種。合計 135 条件。
- 条件ごとに固定シードの400試行、1試行180秒の戦闘を実施。戦闘中の命中・ブロック・通常クリ・強クリと、敵攻撃による被弾、HP/MP、ポーション使用、戦闘不能・復活をシミュレート。
- 敵の行動は単一通常攻撃中心。復活6秒、連戦時の再索敵1秒。HP回復薬40%/15秒、MP回復薬40%/18秒。消費アイテムの通貨コストは未反映。
- 遠距離ビルドの被弾回避は仮の係数であり、実際の移動・射線・AIを再現できたわけではない。
- 戦闘期待値と3分間の実戦近似は異なり、後者を討伐効率の指標とする。

## 7. 検出した問題と手直し案

| 課題 | 結果 | 次の設計判断 |
|---|---|---|
| 感知極の高レベル低下 | Lv140一般5.21体/分、攻撃極7.08体/分 | 感知スキル固有命中補正と感知装備の後期伸長を試験。これ以上の基礎火力増は抑え、罠・探索の強みで差別化 |
| HP極の序盤・中盤の火力不足 | Lv140一般4.48体/分 | 消費HP1.5%・再使用3.8秒・威力係数5.8を試験。ただしPvPと他ビルドのHP装備悪用を別途検証 |
| 攻撃速度極の伸び不足 | Lv140通常4.66体/分、連撃候補あり5.38体/分 | 通常攻撃3回命中でAS依存の追加打撃を1回発動する専用ノードを検討。ユーザーが任意に選ぶ構造を維持 |
| 殴り魔の連戦死亡 | AP極5.49死/3分、HP併用型1.41死/3分 | 魔法型の回復・護魔膜・装備補正・HPへのBP配分を考慮。AP極は高リスクの型として容認するが、同格で全滅するほどにはしない |
| 銃の格上・魔法敵への弱さ | 銃火力立ち撃ちは魔法敵で16.09死/3分 | 遠距離なら常に安全ではない。マニシストの設置障害物、スナイパーの射線調整など独自スキルで対策候補 |
| 幸運属性剣の失敗 | 一般5.03体/分・7.33死/3分。属性剣AP極8.48体/分・0死 | 属性特化と幸運特化を半端に足すだけでは成立しない。強クリ依存の固有特性や幸運装備のHP予算を別検証 |
| 属性の入手コスト未評価 | 高属性120%は一般8.48体/分、AP武器7.08体/分 | 属性120%は採掘・成長合成で仕上げる高価な武器として扱い、入手効率と属性耐性の分布も評価する |

## 8. 重要な未検証項目

- 3体以上の範囲狩り、パーティー狩り、敵集団による範囲攻撃、ボスの特殊行動、PvP。
- 装備の価格・ドロップ率・属性合成の失敗リスクを含む性能予算。
- スキルの前提TMポイント/カード入手、クラスごとの二次スキルをすべて組み込んだ実戦ローテーション。
- HP/MP回復薬の実際の入手コストと回復アイテム使用時間。
- 属性吸収（耐性100%超）、複数属性合成、混合属性スキルの処理。
- 実際の操作・移動・射程・詠唱硬直・ネットワーク遅延に伴う時間損失。
