## 0. 証拠・優先順と警告

過去の議論には**2026年10月版（4職・5カテゴリ10パラメータ・3AP）**と、**2026年11月18〜20日版（基本4タイプ×各2キャラ=8基本職・12能力・4BP）**が混在する。

ここでは後者を現行の優先候補とし、10月版を実装の根拠に使わない。ただし**11月版のスキル・戦闘係数は試算・改訂案**であり、ユーザーの最終承認が確認できない数値は確定扱いしない。

直接確認できた最新の一次資料: `docs/skills_basic_v04_proposal.json`、`docs/skills_basic_v04_proposal.md`（2026-11-20付）、`docs/balance_report_2026-11-18_proposal.md`（2026-11-18付）。2026-10〜11月の会話中にユーザーが決定した記録も参考とするが、これら資料と異なるものは要再確認。

## 1. 今回のPoCに必須の範囲（最優先）

- 立体世界: Tree of Savior の「手描き風の奥行きある2.5D」を表現技法の参照とし、オリジナルの3D床/橋上・橋下/階段/穴/木・建物を作る。見た目と歩行判定がずれないソース・オブ・トゥルースを持つ。
- 遊び: **リアルタイム戦闘、発掘、育成**が核。カードゲームと現金課金は当面必須ではなく、独立モジュールとして後から追加できるよう設計。
- ブラウザ優先。MMO最終500CCU、初期目標50CCU。100人チャンネル方式・共通キャラ/倉庫/ランキングの構想を保持しつつ、実測までは性能保証しない。
- ストーリー: 任意進行。ストーリー未進行でも狩り/発掘/一般フィールド育成が可能。共通のワールド進行で低頻度ユーザーを置き去りにしない。
- 美術: アイテムは承認済みの手描きペインターリー調。原作のキャラクター、音楽、固有マップを流用しない。

## 3. 過去から維持したい設計意図（詳細の新仕様整合は未確認）

- キャラクター1アカウント3体、男/女で戦闘性能差なし、ゲーム内/ログインサイト双方にレベルランキング。
- 武器/防具/アクセサリー/ペットの希少性、重量制、発掘/敵ドロップ、共有倉庫、非同期露店、1:1取引、フィールド投棄など。ただし**古い4職/10能力前提の換算値をそのまま使わない**。
- 敵は定点停止せず巡回・索敵・追跡・攻撃・帰還。討伐後は数秒でマップ内の有効位置に補充。ソロのターゲット占有とパーティ共闘を許容。
- 発掘は全キャラ可能で、マップ/地形/深度によって埋蔵物が変化し、専用職の発掘キャンセル耐性等も将来検討。正確な発掘操作・地層・ドロップ表は未確定。
- 装備品質−10〜＋50%、属性付与/属性強化の独立、強化失敗の封印、ペット無料/イベント/課金段階、課金アイテムによる利便性/火力差などは**将来仕様として記録**。課金自体は現在のPoC必須ではない。

## 4. 11月の24スキル改訂案が持つ重要な実装契約

- 発動受理の瞬間からCTとリソース消費が始まる。動作拘束時間とCTは加算しない。
- 基本攻撃1回の命中/ブロック判定は1度。多段は防御・属性の計算後に分割し、個別会心と±2%ダメージ乱数を付与。
- MISS/BLOCK時もMP/CTは消費。条件付き技の状態は実際に命中した場合だけ消費。
- 原則スキルCTとスキルモーションは攻撃速度ステータスで短縮しない。攻撃速度は通常攻撃向け。
- 90秒バフなどは敵ごとに掛け直しを要求しない。最新24スキル案では持続時間が固定で、10月の『Lv5前後でバフ時間がCTを上回る』案とは異なる。**最新版候補を優先、採用確定は保留**。
- 具体的なダメージ係数は`docs/skills_basic_v04_proposal.json`を参照し、ベースシミュレーションと統合するまで定数としてハードコードしない。
